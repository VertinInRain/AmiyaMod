## 1. 形态系统（核心机制 1）

### 1.1 数据结构（FormManagerPower = 每场战斗 1 份的"形态机 + 战斗追踪器"）
```
FormManagerPower（挂玩家，Amount=0）
├─ enum AmiyaForm { Guard近卫, Caster术士, Medic医疗, DemonLord魔王 }
├─ CurrentForm : AmiyaForm        // 战斗开始 = Guard
├─ FormSwitchTotal : int          // 本场战斗成功形态转换总次数（决意/兔兔之踢 读取）
├─ TurnCardPlayCount : int        // 本回合已打出牌数（领袖奇偶/洪流不息）
├─ TurnAttackPlayedCount : int    // 本回合已打出攻击牌数（洪流不息）
└─ TriggerFormSwitch(ctx, 来源)   // 全模组唯一入口，见 §1.3
```
- 生命周期：战斗开始创建 → 战斗结束销毁；跨战斗不保留（每战重置为近卫）。
- **事件总线 AmiyaEvents**（C# 事件，供各卡/Power 订阅解耦）：
  `OnFormSwitched(新形态, 是否成功)`、`OnDemonLordStackChanged(增量)`、`OnInfectionConverted`、
  `OnBlockGained`、`OnCardPlayed(牌)`、`OnDraw(牌)`、`OnExhausted(牌)`、`OnFullyBlocked(玩家被完全格挡)`。

### 1.2 循环顺序与入形态效果
- 顺序：`近卫 → 术士 → 医疗 → 近卫…`（`(CurrentForm+1)%3`；魔王形态例外见 §2）。
- **进入形态专属效果**（每次"成功"切换结算一次）：
  - 近卫：玩家获得 3 格挡、3 活力(Vigor)。
  - 术士：全体敌人 1 层虚弱。
  - 医疗：抽 1。
- "成功切换"= `CurrentForm` 实际改变；被 燃烬 覆盖的触发不算成功（影响 灵魂堡垒/燎原 等口径，见 Q44）。

### 1.3 TriggerFormSwitch 统一结算（防递归）
```
TriggerFormSwitch(ctx):
  1. 玩家有 EmberPower → 执行燃烬覆盖（§2.3），return（形态不变，不算成功）
  2. next=(CurrentForm+1)%3；CurrentForm=next
  3. FormSwitchTotal += 1；广播 OnFormSwitched(next, 成功=true)
  4. 结算进入形态专属效果（§1.2）
  5. 结算订阅者（燎原/蔓延/灵魂堡垒/铁卫/奔夜…，顺序固定防歧义）
```

## 2. 魔王系统（核心机制 2）

### 2.1 魔王之唤（DemonLordCall，计数 Power，挂玩家）
- **获得**：打出含魔王词条的牌（结算后 +1）；其他：终焉之影（每消耗 1 牌 +1）、存续先兆/时辰已到 的多次打出等。
- **阈值**：Amount 由 <7 变 ≥7 的当次 → "进入魔王形态"（仅一次；之后可继续叠，无上限）。
- 广播 `OnDemonLordStackChanged(+n)` → 裁决据此结算（每 1 层 = 1 次 9 伤，见 Q3）。
- **消耗层数**（她？/众神死亡的荒原）：读 Amount → 清零 → 结算；消耗不触发裁决。

### 2.2 进入魔王形态（一次性、不可逆）
- 本场战斗永久获得：BlackCrown(黑冠)、Ember(燃烬)、Judgment(裁决)；CurrentForm 标记 DemonLord（供 黑冠震荡）。
- 无退出途径。

### 2.3 燃烬（EmberPower）
- 存在时所有 TriggerFormSwitch 不再切换形态，改为：**玩家自选一张手牌消耗**（Q4；空手无事发生）。

### 2.4 黑冠 / 裁决
- **黑冠**：① 造成伤害 ×2（乘性钩子，仅"对敌人"的伤害，自伤不翻倍——旧版 bug 源）；② 每打出 1 张牌自伤 3（口径 Q5）。
- **裁决**：获得魔王之唤的增量事件 → 全体敌人 9 伤（按层逐次，Q3）。

## 3. 词条引擎（魔王/感染/领袖/墓园）

### 3.1 数据表示
- 词条=卡牌实例（及模板）上的**持久标签**，可增删（不容拒绝打魔王/相信明天打领袖/感染变形清空）。
- 实例升级（→+版）发生模板替换时**标签需迁移继承**（Q43）。

### 3.2 触发点
| 词条 | 时机 | 动作 |
|---|---|---|
| 魔王 | 打出含魔王牌结算后 | 魔王之唤 +1（→阈值判定） |
| 感染 | 我方回合**结束**时（作者 2026-09 修订：原"回合开始"改为回合结束） | 弃牌堆中带感染的攻击牌→打击、技能牌→防御（移除全部词条、保留升级态——已裁定）→ 广播 OnInfectionConverted（拒绝哀悼） |
| 领袖 | 打出含领袖牌结算后 | 若本次打出后 TurnCardPlayCount 为奇数 → 落点为抽牌堆（随机洗入，Q6 已裁）；**若该牌带消耗词条则照常消耗（领袖不生效）——作者 2026-09 修订** |
| 墓园 | 战斗开始 | 带墓园牌 → 弃牌堆 |
- 领袖奇偶按"本回合总打出数"计（含重放/青色怒火带出的打出）。

## 8. 通用数值/句式约定
- 伤害/格挡走管线；数值走动态变量；升级只改变量。
- "命中"=独立伤害结算（已裁定）；多段逐段独立结算。
- 计数全部显式字段/事件累加。
- 自伤口径（Q5 已裁，按**卡面文字**区分）：文字"受到 X 点伤害"→ 走伤害管线、**可被自身格挡**（黑冠 3 伤/以血还血 2 伤/待调弦 4 伤）；文字"失去 X 点生命"→ **不可格挡**（以身铸墙/众神荒原 9 生命）。黑冠的 ×2 始终排除对自身的伤害。
